# Smart Product Search & Recommendation Engine 🔍

A machine-learning-powered search and recommendation system for audio devices (speakers, soundbars, Bluetooth audio) built with **Python**, **Streamlit**, **Scikit-Learn**, and **NLTK**.

---

## 🌟 Features

- **Intelligent Fuzzy Search**: Fast, order-agnostic fuzzy matching using token sets and partial ratios to find the closest product even with typos or incomplete keywords.
- **Content-Based Recommendation**: Recommends top similar products using **CountVectorizer** and **Cosine Similarity** on stemmed product feature keywords.
- **Rich Product Cards**: Displays product images, ratings, review counts, discounted & actual prices, similarity percentage badges, and direct store links.
- **Instant Caching**: Precomputed models are cached in memory using `@st.cache_resource` for sub-millisecond query responses.
- **Clean Modern UI**: Responsive layout supporting both Light and Dark modes.

## 🚀 Getting Started

### 1. Set Up a Virtual Environment (Recommended)

```bash
# Create a virtual environment
python3 -m venv .venv

# Activate the virtual environment
# On macOS / Linux:
source .venv/bin/activate

# On Windows:
# .venv\Scripts\activate
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. (Optional) Run Preprocessing

The model files (`data.pkl` and `similarity.pkl`) are automatically generated if they are not present when you launch the app. However, you can manually regenerate them anytime by running:

```bash
python preprocess.py
```

### 4. Run the Streamlit Application

```bash
streamlit run app1.py
```

Open your browser at the local URL displayed in your terminal (typically `http://localhost:8501`).

## 🛠️ Tech Stack

- **Frontend & App Framework**: [Streamlit](https://streamlit.io/)
- **Data Manipulation**: [Pandas](https://pandas.pydata.org/), [NumPy](https://numpy.org/)
- **Text Preprocessing & NLP**: [NLTK](https://www.nltk.org/) (PorterStemmer)
- **Vectorization & Similarity**: [Scikit-Learn](https://scikit-learn.org/) (CountVectorizer, Cosine Similarity)
- **Fuzzy String Matching**: [fuzzywuzzy](https://github.com/seatgeek/fuzzywuzzy) with [python-Levenshtein](https://github.com/scikit-learn/scikit-learn)
